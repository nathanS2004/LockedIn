# Adjustable focus window

## November 14, 2026

The first native passthrough retest appeared to show the room normally on the Quest. Added a controller-placed focus window to `LockedInPassthrough`. It dims the view outside a rectangle held in place for the current session.

| Right controller | Action |
| --- | --- |
| Thumbstick up or down before the first corner | Move the placement plane farther or closer. Line up the cyan dot with the laptop screen. |
| Trigger twice | Select two opposite corners of the screen. After the first pull, a cyan outline previews the window. |
| A | Toggle dimming to compare with the normal view. |
| Thumbstick up or down after placement | Adjust the dimming level. |
| B | Clear the window and place it again. |

Keep the laptop roughly facing you when you place the first corner. The placement plane freezes at that point. Look slightly side to side after placement to check alignment. If the rectangle shifts relative to the screen, reset and adjust the plane depth before placing the first corner.

## Verification

Check that passthrough starts at normal brightness, both corners register, the screen stays clear, and **A** restores normal brightness. Test while seated with the headset on. The focus window is in memory for the session. It does not track a laptop that moves.
